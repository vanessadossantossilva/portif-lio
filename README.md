Portfólio Pessoal

Portfólio desenvolvido como atividade acadêmica para apresentar minha trajetória, formação, habilidades e projetos na área de tecnologia. Criado com HTML5 e CSS3, conta com apresentação pessoal, formação acadêmica, habilidades, projetos, seção de dúvidas e formulário de contato. O projeto também foi utilizado para praticar HTML semântico, estilização e criação de layouts responsivos.
