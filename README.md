# Portfólio Pessoal

Portfólio pessoal desenvolvido como atividade acadêmica, com o objetivo de apresentar minha trajetória, formação, habilidades e projetos na área de tecnologia.

## Tecnologias
- HTML5
- CSS3

## Funcionalidades
- Apresentação pessoal
- Formação acadêmica
- Habilidades
- Projetos
- Seção de dúvidas
- Formulário de contato
- Layout responsivo

Projeto desenvolvido para praticar conceitos de estruturação de páginas web com HTML semântico e estilização com CSS, incluindo organização de layouts, responsividade e efeitos visuais.
